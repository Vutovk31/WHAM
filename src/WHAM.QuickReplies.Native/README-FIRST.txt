WHAM Quick Replies 0.10.0-native-test1

ЭТО НОВАЯ НАТИВНАЯ ТЕСТОВАЯ СБОРКА.
Старые ZIP, CMD, PowerShell и INSTALL-WHAM.cmd не использовать.

Состав:
- WHAM Quick Replies.exe
- macros.json
- VERSION.txt
- README-FIRST.txt

Первый тест:
1. Полностью распакуйте ZIP в новую пустую папку.
2. Запустите WHAM Quick Replies.exe.
3. Откройте Блокнот.
4. Нажмите Ctrl+Alt+1.
5. Должен вставиться текст: «Добрый день! Макрос WHAM работает.»

Редактор:
- дважды щёлкните значок WHAM рядом с часами;
- либо нажмите значок правой кнопкой и выберите «Редактор макросов...».

Безопасность этой сборки:
- нет PowerShell;
- нет CMD-launcher;
- нет VBS;
- нет автоматической установки;
- нет автозагрузки;
- нет принудительного завершения процессов;
- приложение работает с локальным macros.json в своей папке.

Пока не использовать на корпоративных компьютерах без разрешения системного администратора.
Сначала проверить на личном Windows-компьютере.
