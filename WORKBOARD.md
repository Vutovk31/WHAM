# WHAM Quick Replies — Workboard

## Текущий вертикальный сценарий

`macros.json` → глобальная горячая клавиша → заполнение переменных → предпросмотр → Unicode‑текст в активном поле Windows.

## Завершено

- [x] Локальный JSON с пятью редактируемыми макросами.
- [x] Регистрация `Ctrl+Alt+1` — `Ctrl+Alt+5` через Win32 `RegisterHotKey`.
- [x] Вставка многострочного Unicode‑текста через буфер обмена и `Ctrl+V`.
- [x] Значок в системном трее, открытие файла макросов и завершение приложения.
- [x] Проверка обязательных полей и повторяющихся сочетаний при запуске.
- [x] Универсальные переменные `{имя}`, `{номер}`, `{дата}` и пользовательские имена.
- [x] Форма только для недостающих значений, живой предпросмотр и отмена без вставки.
- [x] Отложенное восстановление буфера без перезаписи новых пользовательских данных.
- [x] Видимая диагностика занятой горячей клавиши и локальный журнал ошибок запуска.
- [x] Встроенный Windows self-test: WinForms, шаблоны и RegisterHotKey.
- [x] Windows CI собирает переносимый ZIP и SHA-256.
- [x] Совместимый разбор JSON-массивов во встроенном Windows PowerShell 5.1.
- [x] Графический редактор: добавление, изменение и удаление макросов без правки JSON.
