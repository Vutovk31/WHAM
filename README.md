# WHAM Quick Replies

Локальный инструмент для Windows 10/11: пять редактируемых шаблонов вставляются в активное поле глобальными сочетаниями `Ctrl+Alt+1` — `Ctrl+Alt+5`.

## Запуск

1. Скачайте содержимое репозитория в одну папку.
2. Дважды нажмите `start-wham.cmd`.
3. Убедитесь, что в системном трее появился значок WHAM.
4. Поставьте курсор в письмо, CRM, браузер или комментарий.
5. Нажмите одну из комбинаций `Ctrl+Alt+1` — `Ctrl+Alt+5`.
6. Заполните появившиеся поля, проверьте текст и нажмите **Вставить**. **Отмена** возвращает в исходное приложение без вставки.

Приложение использует встроенный Windows PowerShell 5.1 и не требует установки или прав администратора.

## Редактирование макросов

Откройте меню значка WHAM в системном трее и выберите **Open macros.json**. Для каждого макроса можно изменить:

- `title` — название;
- `hotkey` — сочетание клавиш;
- `text` — текст, где `\r\n` означает перенос строки;
- переменные в фигурных скобках: `{имя}`, `{номер}`, `{дата}` или собственное имя, например `{организация}`.

WHAM находит все уникальные переменные, показывает только нужные поля и обновляет предпросмотр при вводе. Пустые переменные нельзя вставить. После изменения `macros.json` перезапустите WHAM.

## Текущие ограничения

- После вставки текст макроса остаётся в буфере обмена.
- Windows‑приёмка и сборка EXE ещё не выполнены; текущая версия является запускаемым PowerShell‑приложением.

## Конфиденциальность

WHAM работает локально, не подключается к интернету и не собирает содержимое окон или буфера обмена.
