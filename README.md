# WHAM Quick Replies

WHAM Quick Replies — локальное Windows-приложение для многострочных текстовых макросов. Единственная поддерживаемая архитектура — нативное C# WinForms-приложение из `src/WHAM.QuickReplies.Native`.

Текущая тестовая версия: `0.10.0-native-test1`.

## Поддерживаемый сценарий

1. Получить versioned portable ZIP из успешной GitHub Actions-сборки.
2. Проверить SHA-256 из сопровождающего файла.
3. Распаковать ZIP в отдельную папку.
4. Запустить `WHAM Quick Replies.exe`.
5. Убедиться, что значок WHAM появился в системном трее.
6. Поставить курсор в Блокнот или другое обычное текстовое поле Windows.
7. Нажать назначенную комбинацию, например `Ctrl+Alt+1`.
8. Проверить вставку многострочного Unicode-текста.

До успешного Windows Actions build и фактической ручной приёмки portable EXE версия не считается готовой к выпуску.

## Возможности текущего продукта

В продукт входят только:

- создание, редактирование и удаление многострочных текстовых шаблонов;
- локальное хранение в `macros.json`;
- глобальные горячие клавиши;
- вставка Unicode-текста в активное поле Windows;
- системный трей;
- локальное резервное копирование и диагностика;
- portable/release packaging.

OCR, AI, облако, CRM, KPI, звонки, SEO и другие модули не входят в текущий продукт.

## Portable-пакет

Ожидаемая структура тестового пакета:

```text
WHAM_Quick_Replies_v0.10.0-native-test1_win-x64/
├── WHAM Quick Replies.exe
├── macros.json
├── README-FIRST.txt
└── VERSION.txt
```

Рядом с ZIP публикуется файл SHA-256. Версия должна совпадать в имени ZIP, корневой папке, `VERSION.txt`, метаданных приложения/UI и имени checksum-файла.

## Редактирование макросов

Макрос содержит как минимум:

- `id` — локальный уникальный идентификатор;
- `title` — название;
- `hotkey` — глобальная горячая клавиша;
- `text` — многострочный Unicode-текст.

Изменения должны сохраняться локально и не теряться после перезапуска приложения. После изменения горячих клавиш их регистрация должна обновляться без перехода на старые launcher-цепочки.

## Диагностика и self-test

Native EXE поддерживает детерминированную пакетную проверку:

```text
WHAM Quick Replies.exe --self-test
```

Self-test проверяет версию и базовую целостность `macros.json`, пишет локальный `WHAM-self-test.log` и возвращает код завершения процесса. GitHub Actions использует эту проверку до упаковки ZIP.

Автоматизированный self-test и startup smoke-test не заменяют ручную Windows-приёмку: запуск EXE, трей, Блокнот, `Ctrl+Alt+1`, вставка текста, изменение макроса, перезагрузка хоткеев и повторный запуск без потери данных должны быть подтверждены фактически.

## Безопасность пакета

В распространяемом portable ZIP не допускаются `.cmd`, `.bat`, `.ps1` и `.vbs`, `ExecutionPolicy Bypass`, `Invoke-Expression`, скрытые launcher-цепочки, автозагрузка, принудительное завершение чужих процессов или изменение системных настроек.

Старые PowerShell/CMD/VBS-сборки и прежний installer не являются поддерживаемым способом запуска WHAM Quick Replies. Пользователю не требуется и не рекомендуется добавлять WHAM в исключения антивируса.

Цифровая подпись исполняемого файла рассматривается отдельно как будущий внешний release-шаг и не должна считаться выполненной до фактического подписания.

## Конфиденциальность

WHAM Quick Replies предназначен для локальной работы. Текущий продукт не включает облачную синхронизацию, телеметрию, OCR, AI или сбор содержимого пользовательских окон.
