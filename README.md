# WHAM Quick Replies — beta

Локальное приложение для Windows 10/11, которое вставляет пользовательские текстовые макросы в активное поле по глобальным горячим клавишам.

## Что работает в beta

- локальное хранение макросов в `macros.json`;
- пять стартовых сочетаний `Ctrl+Alt+1` — `Ctrl+Alt+5`;
- Unicode и многострочный текст;
- вставка в активное поле через буфер обмена и `Ctrl+V`;
- системный трей;
- перезагрузка макросов без перезапуска Windows;
- установка без прав администратора;
- автозапуск Windows;
- локальный журнал ошибок и статус запуска;
- сохранение пользовательского `macros.json` при повторной установке.

Переменные вида `{имя}` и отдельный визуальный редактор временно не входят в стабильную beta. Такой текст будет вставлен буквально.

## Перед запуском: обязательно полностью распакуйте ZIP

**Не запускайте `install-wham.cmd` или `start-wham.cmd` прямо из окна ZIP-архива.**

Проводник Windows в таком случае может извлечь во временную папку только выбранный CMD-файл. Основной файл `WHAM.QuickReplies.ps1`, `macros.json` и остальные компоненты рядом отсутствуют, поэтому запуск завершается сообщением `Required installer file is missing`.

Правильный порядок:

1. Нажмите правой кнопкой мыши по ZIP-файлу.
2. Выберите **Извлечь всё**.
3. Откройте созданную обычную папку.
4. Убедитесь, что рядом видны `WHAM.QuickReplies.ps1`, `macros.json` и CMD-файлы.
5. Только после этого запускайте установку или portable-версию.

## Установка

1. Полностью распакуйте архив WHAM в отдельную папку по инструкции выше.
2. Дважды нажмите `install-wham.cmd`.
3. После установки рядом с часами должен появиться значок WHAM.
4. Поставьте курсор в Блокнот, письмо, CRM, браузер или мессенджер.
5. Нажмите `Ctrl+Alt+1`, `Ctrl+Alt+2`, `Ctrl+Alt+3`, `Ctrl+Alt+4` или `Ctrl+Alt+5`.

Приложение устанавливается в `%LOCALAPPDATA%\Programs\WHAM Quick Replies` и не требует прав администратора.

## Portable-запуск без установки

1. Полностью распакуйте архив.
2. Убедитесь, что `start-wham.cmd`, `WHAM.QuickReplies.ps1` и `macros.json` находятся в одной папке.
3. Дважды нажмите `start-wham.cmd`.
4. Не перемещайте отдельные файлы из распакованной папки.

## Изменение макросов

1. Нажмите правой кнопкой мыши по значку WHAM в системном трее.
2. Выберите **Открыть macros.json**.
3. Измените нужные поля и сохраните файл.
4. Снова откройте меню WHAM и выберите **Перезагрузить макросы**.

Формат одного макроса:

```json
{
  "id": "unique-id",
  "title": "Название",
  "hotkey": "Ctrl+Alt+1",
  "text": "Текст, который будет вставлен"
}
```

Обязательные правила:

- `id`, `title`, `hotkey` и `text` должны быть непустыми строками;
- `id` не должен повторяться;
- одна горячая клавиша не может использоваться двумя макросами;
- сочетание должно содержать `Ctrl`, `Alt`, `Shift` или `Win` и одну основную клавишу;
- для переноса строки внутри JSON используйте `\r\n` или сохраните многострочную строку корректным JSON-редактором.

Перед автоматической миграцией или восстановлением WHAM создаёт резервную копию исходного файла рядом с `macros.json`.

## Ручная приёмка beta

Перед слиянием в `main` необходимо подтвердить на обычном Windows 10/11:

- [ ] архив полностью распакован, запуск не выполняется из ZIP;
- [ ] установка или portable-запуск проходят без прав администратора;
- [ ] значок WHAM появляется в системном трее;
- [ ] `Ctrl+Alt+1` вставляет русский текст в Блокнот;
- [ ] макрос вставляется в используемый браузер;
- [ ] изменение текста в `macros.json` применяется после команды **Перезагрузить макросы**;
- [ ] перезапуск WHAM не удаляет пользовательские макросы;
- [ ] повторная установка не перезаписывает пользовательский `macros.json`.

## Диагностика

В папке приложения создаются:

- `WHAM-status.txt` — текущий статус, PID и активные сочетания;
- `WHAM-errors.log` — ошибки запуска, чтения файла и регистрации горячих клавиш.

Если сочетание занято Windows или другой программой, измените `hotkey` в `macros.json` и перезагрузите макросы.

## Ограничения beta

- отдельный EXE пока не используется: приложение работает через встроенный Windows PowerShell 5.1;
- приложения, запущенные от имени администратора, могут не принимать вставку от WHAM без такого же уровня прав;
- автоматические тесты не заменяют ручную проверку в конкретной CRM, браузере или почтовом клиенте;
- визуальный редактор и переменные шаблонов отложены до подтверждения стабильности базового ядра.

## Конфиденциальность

WHAM работает локально, не подключается к интернету и не передаёт содержимое макросов, окон или буфера обмена.
